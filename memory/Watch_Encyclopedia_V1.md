## 第一部分：钟表基础

### 1.1 机芯类型

| 类型 | 特点 | 代表品牌 | 优缺点 |
|------|------|---------|--------|
| **手动机械** | 每日上链，传统结构 | 百达翡丽、朗格 | 薄、经典；需手动维护 |
| **自动机械** | 摆陀自动上链 | 劳力士、欧米茄 | 方便、厚重；依赖佩戴 |
| **石英** | 电池驱动，精准 | 精工、卡西欧 | 准、便宜；无机械美感 |
| **光动能** | 光能充电 | 西铁城 | 环保、免换电池；需光照 |
| **Spring Drive** | 机械+石英混合 | Grand Seiko | 精准+机械美感；复杂 |
| **陀飞轮** | 抵消地心引力 | 宝玑、江诗丹顿 | 顶级复杂；昂贵、脆弱 |

### 1.2 机芯结构核心部件

```
动力源 → 传动系 → 擒纵机构 → 摆轮游丝 → 显示系
```

| 部件 | 功能 | 关键参数 |
|------|------|---------|
| **发条盒** | 储存动力 | 动力储备（小时） |
| **擒纵轮** | 控制动力释放 | 频率（Hz） |
| **摆轮+游丝** | 调速核心 | 振频（VPH） |
| **宝石轴承** | 减少摩擦 | 数量（17-50+颗） |

**常见振频：**
- 18,000 VPH（2.5Hz）： vintage表
- 21,600 VPH（3Hz）： 精工、部分瑞士表
- 28,800 VPH（4Hz）： 现代标准（劳力士、欧米茄）
- 36,000 VPH（5Hz）： 高频（真力时El Primero）

## 第四部分：鉴定与防伪

### 4.1 通用鉴定流程

```
第一步：外观检查（表盘、指针、刻度）
第二步：表壳检查（刻字、打磨、材质）
第三步：机芯检查（打磨、刻字、结构）
第四步：功能测试（走时、日历、计时等）
第五步：资料核对（保卡、序列号、年份）
```

### 4.2 各品牌鉴定要点

#### 劳力士 Rolex
| 检查点 | 真品特征 | 假货常见问题 |
|--------|---------|-------------|
| **放大镜** | 日期放大2.5倍，居中 | 放大不够，偏移 |
| **表冠logo** | 五爪清晰，抛光精细 | 模糊，比例失调 |
| **内圈刻字** | 2008年后有，激光刻 | 无或印刷 |
| **机芯** | 自动陀有品牌刻字 | 空白或粗糙 |
| **重量** | 钢款150g+，压手 | 过轻 |

#### 欧米茄 Omega
- 同轴擒纵（Co-Axial）机芯结构独特
- 防磁技术（METAS认证）
- 序列号可在官网查询

#### 百达翡丽 Patek Philippe
- 机芯打磨级别最高
- 日内瓦印记（PP印记）
- 表耳螺丝为特殊工具设计

### 4.3 常见造假手段

| 类型 | 特征 | 鉴别方法 |
|------|------|---------|
| **改装表** | 换盘、换圈、换针 | 对比原厂配置 |
| **拼装表（Frankenwatch）** | 不同表款零件组装 | 检查部件一致性 |
| **重印盘** | 老旧表盘重新印刷 | 放大镜看印刷质量 |
| **后镶钻** | 原表后加钻石 | 检查镶嵌工艺 |
| **假保卡** | 保卡信息不匹配 | 官方渠道核对 |

## 第六部分：维护与保养

### 6.1 日常佩戴注意

| 项目 | 建议 |
|------|------|
| **防水** | 不要戴非潜水表游泳；潜水表定期检查防水圈 |
| **防磁** | 远离手机、音箱、皮包扣；受磁需消磁 |
| **防震** | 避免剧烈运动时戴正装表 |
| **温差** | 避免桑拿、热水澡（防水圈老化） |

### 6.2 保养周期

| 项目 | 周期 | 费用参考 |
|------|------|---------|
| **全面保养** | 5-7年 | 劳力士¥3,000-5,000；PP ¥8,000+ |
| **更换防水圈** | 2-3年 | ¥200-500 |
| **抛光** | 按需（尽量少抛） | ¥500-1,500 |
| **更换皮带** | 1-2年 | ¥300-2,000 |

### 6.3 常见问题处理

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| **走时不准** | 受磁、动力不足、需要保养 | 消磁、上链、送修 |
| **日历跳不准** | 机芯问题 | 送修 |
| **表冠拧不动** | 螺纹损坏、防水胶圈老化 | 送修 |
| **起雾** | 防水失效 | 立即送修，防止机芯生锈 |
